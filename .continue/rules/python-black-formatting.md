Always format Python code to comply with Black formatter standards:
- Use 4 spaces for indentation
- Maximum line length of 88 characters
- Use double quotes for strings (not single quotes)
- Add trailing commas in multi-line structures
- Use consistent spacing around operators and after commas
- Break long lines appropriately before binary operators
- Ensure proper blank lines (2 before top-level definitions, 1 between methods)
- No unnecessary parentheses except for line continuations
